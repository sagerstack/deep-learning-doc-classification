```python
def _emit_model_inference(r: "InferenceResult") -> None:
    """Emit a model.inference structured log event for a single InferenceResult.

    Field schema per CONTEXT.md: model_id is the slug (model_name),
    top3_classes is a list of {class, score} dicts sorted by probability desc.
    """
    # Top-3 classes from probabilities
    indexed = sorted(
        enumerate(r.probabilities),
        key=lambda ix_p: ix_p[1],
        reverse=True,
    )[:3]
    top3 = [
        {"class": RVL_CDIP_LABELS[i], "score": float(p)}
        for i, p in indexed
    ]
    log.info(
        "model.inference",
        event_type="model.inference",
        model_id=r.model_name,
        predicted_class=r.predicted_class,
        confidence=float(r.confidence),
        top3_classes=top3,
        model_latency_ms=float(r.inference_time_ms),
    )
```

Rationale:
- `model_id = r.model_name` uses the slug (e.g. `cnn_baseline`, `multimodal_gat`), NOT `r.display_name` (which is the human-readable label). CONTEXT.md mandates the slug.
- `top3_classes` is computed here because `InferenceResult` carries the full `probabilities` list but no pre-computed top-k; doing it in the helper keeps the dataclass unchanged.
- `float(...)` coercions prevent torch tensor or numpy types from leaking into the log payload (JSON serialization would fail silently in some processors).

Do NOT emit `model.inference` for the placeholder branch where BoC is unavailable (`predicted_class="(OCR unavailable)"`, `confidence=0.0`) — that is an intentional skip, not a real inference. The existing placeholder append is preserved but not logged.
