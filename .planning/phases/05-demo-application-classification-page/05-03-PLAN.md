   - constructor_kwargs: dict
   - checkpoint_path: str (relative to project root)

   - needs_text_density: bool

2. **MODEL_SPECS list** — one ModelSpec per model:

   a) CNN Baseline: model_type="CNN", no model_class (uses ResNet-50 fc layer directly), checkpoint_path="models/exp14b_finetuned_resnet50_cnn.pt", graph_type="none", no special features needed

   b) Fusion GraphSAGE (exp16): model_type="GNN", FusionGraphSAGE, constructor_kwargs={"in_channels": 2048}, checkpoint_path="models/exp16_fusion_featknn_graphsage.pt", graph_type="feature_knn", needs_global_feat=True

   d) BoC GraphSAGE (exp25): model_type="GNN+OCR", HybridGraphSAGE, constructor_kwargs={"node_dim": 2120}, checkpoint_path="models/exp25_boc_sage.pt", graph_type="feature_knn", needs_global_feat=True, needs_boc=True (BoC is concatenated into node features for this model)

   e) Gated BoC GraphSAGE (exp26): model_type="GNN+OCR", GatedBoCGraphSAGE, constructor_kwargs={"cnn_dim": 2050, "boc_dim": 70, "proj_dim": 16}, checkpoint_path="models/exp26_gated_boc.pt", graph_type="gated_boc", needs_global_feat=True, needs_boc=True

   f) Attention Pool GraphSAGE (exp27): model_type="GNN", AttentionPoolFusionSAGE, constructor_kwargs={}, checkpoint_path="models/exp27_attn_pool.pt", graph_type="feature_knn", needs_global_feat=True

   - Takes device string/torch.device
   - Loads ResNet-50 feature extractor from exp14b checkpoint (reuse src.features.load_trained_resnet50 + create_feature_extractor for layer4 and avgpool outputs)

<task type="auto">
  <name>Task 2: Create single-image inference pipeline</name>
  <files>app/src/services/inference.py</files>
  <action>
Create app/src/services/inference.py with:

1. **InferenceResult dataclass:**
   - model_name: str
   - display_name: str
   - model_type: str
   - predicted_class: str (label name)
   - predicted_index: int
   - confidence: float (top-1 softmax probability)
   - probabilities: list[float] (all 16 class probabilities)
   - inference_time_ms: float

2. **PipelineResult dataclass:**
   - results: list[InferenceResult] (sorted by confidence descending)
   - layer4_features: torch.Tensor ([2048, 7, 7] for visualization)
   - text_density: torch.Tensor | None ([7, 7] if computed)
   - grid_edge_index: torch.Tensor (for grid graph visualization)
   - knn_edge_index: torch.Tensor (for kNN graph visualization)
   - graph_stats: dict (num_nodes, grid_edges, knn_edges, avg_degree)
   - total_time_ms: float
   - feature_extraction_time_ms: float
   - graph_construction_time_ms: float

3. **run_inference_pipeline(image: PIL.Image, registry: dict, device: torch.device) -> PipelineResult:**
   - Preprocess image: Convert to RGB, apply ResNet50_Weights.IMAGENET1K_V2.transforms()
   - Extract features: Run feature extractor to get layer4 [2048, 7, 7] and avgpool [2048]
   - Build grid graph: build_grid_edge_index(7, 7, k=8) — for visualization
   - Build feature-kNN graph: compute kNN edges from features (for visualization + GNN models that use feature_knn)
   - Optionally compute text density: Try to import and run src.text_features (catch ImportError gracefully — doctr may not work on all systems)
   - Optionally compute BoC features: Try to import and run src.ocr_features (catch ImportError — tesseract may not be installed)
   - Run CNN baseline: Pass preprocessed image through full ResNet-50, get logits, softmax
   - Run each GNN model based on its ModelSpec:
     - Build the appropriate graph Data object using the spec's graph_type
     - For feature_knn models: use kNN edges + PE + optional BoC concat
     - For gated_boc: use feature_map_to_graph_gated_boc with separate x_boc
     - Forward pass, softmax, extract predictions
   - Time each step and model individually
   - Sort results by confidence descending
   - Return PipelineResult

Key implementation details:
- Use torch.no_grad() for all inference
- Use time.perf_counter() for timing
- Handle MPS device for model inference (text density extraction handles its own CPU fallback)
- If BoC features are unavailable (tesseract not installed), skip models that need_boc=True and note in results
- If text density unavailable, skip models that need_text_density=True (currently none of the 6 models need it for inference — text density is only for visualization)
- The CNN baseline forward pass: just run the full ResNet-50 (with fc head) on the preprocessed 224x224 tensor
- For GNN forward pass: create a single-sample PyG Batch with batch=torch.zeros(49, dtype=long)
  </action>
