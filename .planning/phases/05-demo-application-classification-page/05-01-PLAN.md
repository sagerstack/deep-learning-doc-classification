**FusionGraphSAGE** (used by exp16 checkpoint):
- Constructor: in_channels=2048, hidden=256, gnn_embed=128, num_classes=NUM_CLASSES, dropout=0.5, global_dim=2048
- Architecture: SAGEConv(in_channels, hidden) -> ReLU -> Dropout -> SAGEConv(hidden, gnn_embed) -> ReLU -> Dropout -> global_mean_pool -> Sequential(Linear(global_dim+gnn_embed, 512), ReLU, Dropout, Linear(512, num_classes))

- Source: .lab/workspace/exp_16_fusion_gnn.py lines 150-185

**FusionGAT** (used by exp23 checkpoint):
- Constructor: in_channels=2048, hidden=256, embed=128, num_classes=NUM_CLASSES, dropout=0.5, heads=4
- Architecture: GATConv(in_channels, hidden//heads, heads=heads, dropout=dropout) -> ReLU -> Dropout -> GATConv(hidden, embed, heads=1, concat=False, dropout=dropout) -> ReLU -> global_mean_pool -> Sequential(Linear(2048+embed, 512), ReLU, Dropout, Linear(512, num_classes))
- Forward: same pattern as FusionGraphSAGE, squeezes global_feat if dim==3
- Source: .lab/workspace/exp_23_gnn_arch_comparison.ipynb cell 3

**GatedBoCGraphSAGE** (used by exp26 checkpoint):
- Constructor: cnn_dim=2050, boc_dim=70, proj_dim=16, hidden_channels=256, embed_channels=128, global_channels=2048, num_classes=NUM_CLASSES, dropout=0.5
- Architecture: text_gate = Sequential(Linear(boc_dim, proj_dim), Sigmoid()); text_proj = Linear(boc_dim, proj_dim); GNN on concat(cnn_features, gated_boc_projection) node features; fusion with global_feat
- Forward: takes (x, edge_index, batch, global_feat, x_boc). Computes gate = text_gate(x_boc), projected = text_proj(x_boc), gated = gate * projected. Concatenates [x, gated] for GNN input. Then standard SAGEConv -> ReLU -> Dropout -> SAGEConv -> ReLU -> global_mean_pool -> BatchNorm fusion with global_feat -> Linear classifier.
- The node_dim for conv1 is cnn_dim + proj_dim (2050+16=2066)
- Reconstruct from exp26 notebook cell 4 constructor args and the checkpoint state_dict key patterns: text_gate.0.weight [16,70], text_proj.weight [16,70], conv1.lin_l.weight [256,2066], classifier.weight [16,2176]
- Uses BatchNorm on gnn_embed and cnn global_feat before fusion (same as HybridGraphSAGE pattern)

**AttentionPoolFusionSAGE** (used by exp27 checkpoint):
- Constructor: node_dim=2050, hidden_channels=256, embed_channels=128, global_channels=2048, num_classes=NUM_CLASSES, dropout=0.5
- Architecture: Same GNN backbone as HybridGraphSAGE but replaces global_mean_pool with learned attention pooling: attn_gate = Sequential(Linear(embed_channels, 1)); softmax over nodes per graph; weighted sum
- Forward: takes (x, edge_index, batch, global_feat). After conv2, compute attention weights per node: attn_scores = attn_gate(x), apply softmax per graph using scatter, weighted sum pooling. Then BatchNorm fusion with global_feat -> Linear classifier.
- Reconstruct from exp27 constructor args and checkpoint key pattern: attn_gate.0.weight [1,128]

```python

    features: torch.Tensor,       # [C, H, W] e.g. [2048, 7, 7]
    global_feat: torch.Tensor,    # [C] e.g. [2048]
    ocr_boc: torch.Tensor,        # [H*W, 70] BoC features per grid cell
    label: int,
    k: int = 8,                   # feature-kNN k
) -> Data:
```

1. Reshape features to [H*W, C] node features
2. Add 2D positional encoding -> [H*W, C+2] (reuse existing add_positional_encoding_2d)

4. Create Data object with x=node_features [49, 2050], edge_index from kNN, y=label
5. Attach global_feat as data.global_feat = global_feat.unsqueeze(0) [1, 2048]
