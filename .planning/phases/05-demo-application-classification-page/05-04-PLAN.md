Create app/src/services/visualization.py with the following functions. CRITICAL: Set `matplotlib.use("Agg")` at module level before any matplotlib imports (non-interactive backend for server).

1. **fig_to_base64(fig) -> str:**
   - Convert matplotlib figure to base64-encoded PNG string
   - Save to BytesIO, encode, close figure with plt.close(fig)
   - Returns string suitable for `<img src="data:image/png;base64,{result}">`

2. **generate_activation_heatmap(layer4_features: torch.Tensor, original_image: PIL.Image) -> str:**
   - Input: layer4_features [2048, 7, 7], original_image (any size PIL Image)
   - Mean across channel dim -> [7, 7] activation map
   - Normalize to [0, 1]
   - Resize original image to 224x224
   - Create figure: show image, overlay activation with cmap="jet", alpha=0.4, interpolation="bilinear"
   - Return base64 PNG
   - Figure size: (3, 3), dpi=100, transparent background, no axes

3. **generate_text_density_html(text_density: torch.Tensor | None, primary_color: str = "#24389c") -> str:**
   - Input: text_density [7, 7] tensor with values in [0, 1], or None
   - If None: return placeholder HTML saying "Text density not available"
   - Generate 49 divs in a CSS grid (grid-cols-7 grid-rows-7)
   - Each div: aspect-square rounded-sm, background=primary_color, opacity=value
   - Return HTML string for embedding in template

4. **generate_graph_svg(edge_index: torch.Tensor, grid_h: int = 7, grid_w: int = 7, width: int = 280, height: int = 280, edge_color: str = "#c5c5d4", node_color: str = "#24389c") -> str:**
   - Generate SVG string for a graph with nodes on a 7x7 grid
   - Nodes: circles at grid positions with r=4
   - Edges: lines connecting nodes as per edge_index
   - Padding: 20px
   - Use viewBox for scaling
   - Return complete SVG string (can be embedded with {{ svg | safe }} in Jinja2)

5. **generate_probability_bars_html(probabilities: list[float], labels: list[str], top_n: int = 3) -> str:**
   - Input: 16-class probability list, label names, number of bars to show
   - Sort by probability descending, take top_n
   - Generate HTML for horizontal bar chart:
     - Each bar: flex row with label (w-20), progress bar div (flex-1 h-3 rounded-full), percentage text
     - Top bar uses bg-primary color, others use bg-slate-300
   - Match the Stitch prototype styling (font-label text-xs, etc.)
   - Return HTML string

6. **generate_16class_bar_chart(probabilities: list[float], labels: list[str], predicted_index: int) -> str:**
   - Input: all 16 class probabilities, labels, which class was predicted
   - Create matplotlib bar chart: 16 bars, predicted class in primary color (#24389c), others in slate-200 (#e2e8f0)
   - X-axis: class labels rotated 45 degrees
   - Y-axis: probability
   - Figure size: (5, 2.5), tight layout
   - Return base64 PNG

7. **generate_node_importance_html(node_features_post_conv: torch.Tensor | None) -> str:**
   - Input: post-aggregation node features [49, embed_channels] or None
   - If None: return placeholder
   - Compute per-node importance as L2 norm of feature vector
   - Normalize to [0, 1]
   - Generate 49 divs in 7x7 CSS grid, same pattern as text_density
   - Return HTML string

8. **generate_original_image_base64(image: PIL.Image, max_size: int = 400) -> str:**
   - Resize image maintaining aspect ratio to fit max_size
   - Convert to base64 PNG
   - Return base64 string for display in upload zone

All functions must:
- Be pure (no side effects, no file I/O)
- Handle edge cases (None inputs, empty tensors)
- Use the MD3 color tokens from the Stitch prototype (#24389c primary, #c5c5d4 outline-variant, etc.)
