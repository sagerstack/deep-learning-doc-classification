  <action>
**Update app/src/main.py lifespan:**
- Import load_all_models from app.src.services.model_registry
- Import device detection from src.config (Config class)
- In lifespan startup: detect device, call load_all_models(device), store in app.state.registry and app.state.device
- Log startup info: device, number of models loaded, memory usage

**Update app/src/routes/classify.py POST /classify:**
- Accept UploadFile parameter for image upload
- Accept optional Form parameter for sample_name (when user clicks preloaded sample)
- Convert upload to PIL Image (read bytes, open with PIL, convert to RGB)
- If sample_name provided instead, load from app/src/static/samples/{sample_name}
- Get registry and device from request.app.state
- Call run_inference_pipeline(image, registry, device)
- Call visualization functions to generate all visual elements:
  - generate_activation_heatmap(result.layer4_features, image)
  - generate_text_density_html(result.text_density)
  - generate_graph_svg(result.grid_edge_index) for grid graph
  - generate_graph_svg(result.knn_edge_index) for kNN graph
  - generate_original_image_base64(image)
  - For each model result: generate_probability_bars_html, generate_16class_bar_chart
  - For detailed analysis: generate_node_importance_html (if available)
- Build template context dict with all visualization outputs + pipeline results
- Check HX-Request header: if HTMX request, render only "results_section" block via Jinja2Blocks TemplateResponse with block_name
- If full page request (non-HTMX), render full base.html

```python
    "results": [InferenceResult, ...],  # sorted by confidence

        {
            "result": InferenceResult,
            "bar_chart_b64": str,
            "probability_bars_html": str,
            "node_importance_html": str,
        }, ...
    ],
    "total_time_ms": float,
    "feature_time_ms": float,
    "graph_time_ms": float,
}
```
